# AQUI NET HUB

Base technique initiale du projet AQUI NET HUB.

## Technologies
- React + TypeScript
- Vite
- CSS responsive

## Démarrage local
1. Installer Node.js (version LTS).
2. Dans ce dossier, exécuter `npm install`.
3. Exécuter `npm run dev`.

## Compilation
`npm run build`

## Sécurité
- Ne jamais placer de clés API, mots de passe ou secrets dans le code frontend.
- Les accès à la base de données et les paiements seront gérés côté serveur.
- Les migrations SQL et règles d'accès seront ajoutées avant l'activation des comptes et paiements.

## État
Socle frontend initial uniquement. Aucun compte, paiement, publicité ou stockage n'est encore activé.
